## Part 1: Websites & APIs **[40 marks]**

Time for a bit of JavaScript and Python. What's not to hate? (~~JavaScript~~ - `wizzdom`)

### Setup
1. Fork and clone the [webmaster exam 2026 egm starter pack](https://github.com/novanai/webmaster-exam-2026-egm-starter-pack).
    - Make sure the repository is private and invite `novanai` as a collaborator.
2. Get familiar with the code.
    - There is a backend API written with [FastAPI](https://fastapi.tiangolo.com/).
    - The backend API has two endpoints:
        - `/submit` which accepts POST requsts
        - `/order` which accepts GET requests
    - You can view full documentation at <http://localhost:8000/docs> when you run the backend.

### Task 1 - SQL

Finish writing the callbacks for the two api endpoints.
- `/submit` should insert the order into the database, and return the new row's `id`.
- `/order` should retrieve the requested order from the database and return it, or `None` if the order doesn't exist.

### Task 2 - JS & CSS

Create a frontend using a framework of your choice.

It should have two pages, one to submit an order for a hoodie, and another to view a hoodie order.

#### Order Page

Contains a form with the following inputs:
- Username
- Hoodie Colour (Black/White)
- Size (XS/S/M/L/XL)
- Amount

On submission this form should send a POST request to `/submit` on the backend with the form inputs as the request body.

#### View Order Page

This page should:
- take a URL parameter, e.g. `/order/{id}`
- send a GET request to `/order` on the backend using the `id`
- display the order, or an error message if the order does not exist 

Make the order page pretty using [tailwind](https://tailwindcss.com/).

### Task 3 - Docker
1. Create [Dockerfiles](https://fastapi.tiangolo.com/deployment/docker/#dockerfile) for both the backend and frontend.
2. Create a [docker compose](https://docs.docker.com/compose/gettingstarted) file which defines services for the backend and frontend.
    - It should build the images using your Dockerfiles
    - Don't forget to mount the database file as a volume!
